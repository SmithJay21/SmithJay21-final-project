## GreenTech Solutions Website
GreenTech Solutions is a multi-page responsive website designed for a fictional environmental technology startup. The website showcases eco-friendly products and services such as solar energy systems, smart recycling technology, and water monitoring systems.

The goal of the website is to inform users about sustainable technology, engage visitors with interactive features, and encourage potential customers to explore GreenTech’s offerings.

## features
Multi-page design
Product filtering system using JavaScript
Interactive contact form with validation
Newsletter subscription form
Accessible design (alt text, labels, semantic HTML)
Mobile-friendly layout using responsive CSS
